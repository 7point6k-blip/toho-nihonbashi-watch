# TOHOシネマズ日本橋 バイト求人ウォッチャー

10分ごとに公式求人サイト（tohocinemas-recruit.net）を開いて、劇場名に「日本橋」を含む求人を職種名に関係なく探し、スマホ（ntfyアプリ）に通知します。

通知されるもの
- 🎬 新しい求人（どんな職種名でも）
- 🎬 一度消えた求人の再掲載
- 掲載終了
- ⚠️ 30分以上サイトを読めないとき（以後12時間ごと）／✅ 復旧
- 📡 週1回の「正常に動いています」報告（これが来なければ止まっている合図）

止めたいとき: Actions タブ → 「TOHOシネマズ日本橋 求人チェック」→ … → Disable workflow
手動で今すぐ確認: 同じ画面の「Run workflow」（テスト通知にチェックを入れると通知テストも可）
